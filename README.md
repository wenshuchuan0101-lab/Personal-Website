# 关于想象力的一切

单屏首页使用提供的蓝白天体图片，中英文同屏以高饱和橙色显示。背景保持原图颜色。流星定时从左向右沿天体边缘外侧的圆弧划过，点击天空空白处也会触发，并直接进入个人介绍页。月面和文字区域不触发流星。

个人介绍页锁定为一屏，鼠标滚轮、键盘和手机上下滑动均不会展开下面的内容，左侧半透明浮栏已去掉。原来的独立模式选择幕已移除；「快速浏览」和「观赏模式」放在介绍页右侧原星形装置的位置，使用多层圆环、刻度、交叉轨道和缓慢转动的细节包围两个圆角细框按钮。手机上装置排列在姓名下方，两个按钮始终位于屏幕内。右上角四芒星可切换界面中英文。

点击「快速浏览」后渐白进入成长过程，按照提供的《孟紫幽》文档，保留 14 条成长记录、4 个图片影像作品和 3 个交互／游戏作品。导航移至顶部固定显示，保留半透明与模糊效果，高度为旧侧栏宽度的一半（桌面 39px、窄屏 28px）；点击「个人介绍」返回锁定的入口页。成长过程与作品分区独立切换，不能上下滚动跨越分区。页面采用蓝、橙、米白的整块配色。作品封面及独立详情目前留空，没有编写文档中尚未提供的作品简介。观赏模式渐黑后保留空幕，可通过返回按钮或 Esc 返回介绍页。

作品预览采用一件作品一整屏的布局，共 7 件。点击顶部作品分类后，左边展开轴心贴在屏幕左边缘的半面时钟，只露出右半个钟面；表盘已放大，外围横向卡片相应向外让开。卡片可通过滚轮、触屏上下滑动或鼠标拖动循环浏览，第七件后接第一件，第一件前接第七件，首尾均不会出现空白。中间卡片最大，左右相邻的卡片按距离逐级缩小，并沿弧形退后。罗马数字 I—VII 与作品序号对应，自动均分完整 360°，随卡片同步转动。只有中间卡片对应的数字及内外刻度段向外凸出，其余刻度段保持在原半径。指针记录上次点击确认的作品，并始终指向该作品在旋转表盘中的数字；首次没有确认记录时指向第一个作品。滑动预览不会改变指针记住的作品。

滑到中间的卡片会立即更新背后的作品预览；轮盘展开时介绍区全部文字与「进入」提示立即隐藏，海报和渐变遮罩继续显示，收起动画结束后文字再淡入，避免同时出现。点击卡片确认，轮盘收起，作品页锁定，左侧留下四芒星，点击星星可重新展开。轮盘收起时，滚轮、上下滑动、PageDown 和 End 均不会切换作品。轮盘还支持上下方向键、Home、End 定位，Enter 确认，Esc 或点击外围收起。

每个作品以自己的海报铺满全屏，使用 `object-fit: cover` 裁切。介绍文字区域宽度为屏幕的五分之二，贴左边或右边；深色遮罩独立覆盖半屏，从相邻屏幕边缘向中线逐渐变透明，在屏幕二分之一的位置完全消失，右侧布局镜像处理。介绍区显示标题、简介（填写后显示）、职责、工具、周期和原文奖项，下方「进入」打开独立的 `project.html?work=作品ID&lang=zh` 详情页。第一个作品的介绍区在左侧，其余作品目前也默认左侧，可按海报构图调整。《鱼龙舞》已使用提供的原始海报 `assets/yulong-dance-poster.png`，《Zephyrus》已接入提供的五张原始海报，《怪诞花园》使用提供的原图 `assets/grotesque-garden-poster.png`，《花房》使用 `assets/flower-room-poster.png`，裁切位置为 `35% 50%`，优先保留左侧、更多裁去右边；其余作品的海报和未提供的简介保持空值，空海报位显示深蓝底色。时钟位于卡片内侧，卡片外围保持开放，没有包裹卡片的半圆底板。

《Zephyrus》的全屏展示使用横向海报展开布局，顺序为浅色遗迹、紫色斜坡、风车、蓝色夜景、洞窟。屏幕宽度均分八份，默认第一张占四份（二分之一），其余各占一份（八分之一）；鼠标移入某张时该张平滑展开为四份，其余都收为一份。每个分区内的海报放在居中的矩形黑框里，框外上下左右全部填纯黑色，顶部从固定导航下方留边，上下黑边使用加宽后的 `clamp(18px, 4.5svh, 48px)`。`poster-panels.css` 的 `--poster-frame-x`、`--poster-frame-y` 分别调整左右和上下留边。离开后保留当前展开项。手机点按可切换，键盘左右方向键、Home、End 也可选择。裁切位置按参考标注配置，原图未加黑色标记或修改；介绍文字不拦截海报悬停，「进入」链接仍可点击，轮盘展开时仍隐藏文字并暂停海报交互。

个人介绍中的两个名字占用同一个位置，默认显示白色「孟紫幽」，鼠标移入时向左翻页露出橙色「梅子雨」，移出时翻回；触屏点击或键盘 Enter／Space 也能切换。两页的中英文跟随语言切换，姓名与别名仍在 `portfolio-data.js` 的 `profile.name`、`profile.alias` 修改。

## 修改快速浏览

- `portfolio-data.js`：全部个人资料、成长记录、作品标题、分类、职责、工具、制作周期和奖项，均提供中英文。新增或删除 `timeline` 条目及 `projects` 条目即可调整数量，编号与作品数量自动更新。
- `portfolio.css`：开头的 `--portfolio-blue`、`--portfolio-navy`、`--portfolio-orange`、`--portfolio-paper` 调整配色；字号、作品比例和动效也在此文件修改。
- `work-wheel.css`：顶部导航、作品单屏锁定与半圆轮盘样式。`--quick-nav-height` 调整顶栏高度，`--wheel-radius` 调整轮盘半径，`--portfolio-side` 调整正文左侧留白；轮盘颜色、透明度、边线和开合速度均可编辑。
- `work-posters.css`：方块轮盘、全屏海报和五分之二介绍区；`--wheel-card-size`、`--wheel-card-gap` 控制方块尺寸和间距，`.project-brief` 控制图层宽度、透明渐变和文字布局。
- `work-clock.css`：半面时钟、内外分段圆弧、罗马数字、指针与横向卡片布局；`--clock-scale` 调整表盘大小，`--wheel-card-width` 调整中间卡片宽度。`portfolio-data.js` 的 `workClock.cardAngleStep` 调整卡片之间的角距，`activeLift` 调整唯一凸出段的距离，`cardScaleFalloff` 调整卡片向两侧缩小的强度。时钟数字间隔始终自动计算为 `360 / 作品数量`，保持整圈排满。表盘和指针均为可编辑 SVG。
- `poster-panels.css`：海报按 4:1:1:1:1 展开、悬停过渡与键盘焦点样式；图片顺序和裁切位置保存在作品的 `posterPanels`，可逐张替换。展开权重在 `portfolio.js` 的 `expandedPosterWeight` 中调整。
- `portfolio.js`：内容渲染、分区切换、轮盘实时预览、确认、拖动与语言联动；`renderWheel()` 自动读取作品清单，`updateWheel()` 根据滚动位置沿半圆排布方块并更新预览。
- `project.html`、`project-detail.js`、`project-detail.css`：独立作品详情页；「返回」恢复当前作品及语言，详情内容继续从同一份作品配置读取。

成长过程使用深蓝底、蓝紫色山体的折线时间图。学习内容为白字，作品为橙字；节点带轻微辉光，滚动时沿时间推进，抵达最新记录后最后一段折线变橙色，早期节点和文字缩小，视角拉远，后方山脊向上延伸。延伸部分没有虚构日期或经历。下方箭头可以逐项查看所有记录，支持键盘左右方向键、Home 和 End；系统设置减少动态效果时，默认显示完整山体，箭头仍可查看各阶段。

山丘上下沿均使用圆润曲线，下沿从第一个成长节点出发并轻微起伏，下方保留深蓝留白。山体使用上浅下深的蓝紫渐变，最深处与背景色 `#080820` 完全相同，底部自然融入背景。完整视图中，过去到现在占整张图左侧约三分之一，余下部分为向上延伸的山丘轮廓。

整条轮廓以加速上升的曲线为基础：早期保持低缓，之后逐步抬升，越往后坡度越大；局部起伏围绕这条总趋势变化。现在节点之后有几次明显冲高、回落，再向更高处攀升；后段大幅波折使用圆润曲线衔接，尾端继续加速上扬。

经历节点按记录的起始月份分布，间距不再等分，作品段采用更明显的上升与回落。日期统一放在图下方的日期轴，节点用竖直细线向下连接；上方仅显示学习内容或作品名。缩小后日期会自动避让，当前阶段日期始终保留，其余记录可通过下方箭头查看。

- `portfolio-data.js` 的 `timeline` 继续保存全部成长文案，`kind: "study"` 显示白色学习内容，`kind: "work"` 显示橙色作品；学习阶段的 `works` 字段仍以橙色显示。
- `growthChart.historyWaves` 调整各节点相对总趋势的局部起伏，仅用于造型，不是能力或成绩数据。增添成长记录后，没有填写波动的节点也会自动生成造型。`growthChart.acceleration` 控制整条曲线的加速程度，默认 2.6；`trendRise` 控制整体上升幅度，默认 650。`growthChart.historyShare` 调整过去到现在所占比例，默认 `1 / 3`；`growthChart.scrollDistance` 调整这段滚动叙事的长度。
- `growthChart.futureWaves` 调整后段的大幅波折，每项为 `[沿后段的位置, 相对总趋势的高度变化]`；正值抬高波峰，负值加深回落。所有波峰和谷底之间仍为柔和的曲线。
- `growth-chart.css` 调整深蓝、蓝紫、白和橙的配色、辉光和布局；`growth-chart.js` 负责折线、山体、视角缩放与当前记录。所有图形均为可编辑 SVG，没有固定成图片。

将海报放在 `assets/` 下，在相应作品中填写：

```js
poster: "./assets/作品海报.jpg", // 全屏背景，也用于轮盘缩略图
posterPosition: "center",       // 裁切中心，例如 "65% 40%"
introSide: "left",              // "left" 或 "right"
introduction: { zh: "", en: "" }, // 预览图层中的简短介绍
cover: "",                     // 可选：单独设置轮盘缩略图
```

`poster` 为空时兼容读取 `cover`；两个路径都为空时只显示深蓝底，不请求不存在的图片。轮盘方块优先使用 `cover`，其次使用 `poster`。所有图层侧边、文字和素材路径均可逐件作品编辑。

多张海报可在同一作品上添加 `posterPanels` 数组，例如：

```js
posterPanels: [
  { src: "./assets/zephyrus-poster-01.png", position: "75% 50%" },
  { src: "./assets/zephyrus-poster-02.png", position: "48% 50%" },
  { src: "./assets/zephyrus-poster-03.jpg", position: "49% 50%" },
  { src: "./assets/zephyrus-poster-04.jpg", position: "54% 50%" },
  { src: "./assets/zephyrus-poster-05.png", position: "48% 50%" },
],
```

数组顺序即从左到右的展示顺序；`position` 为每张图的裁切中心。展开状态在切换中英文时保留，重新进入页面默认展开第一张。独立详情页的素材配置仍在 `detail` 中，本轮只增加全屏作品展示里的五张海报。

每个作品的 `detail` 对象预留后续素材：

```js
detail: {
  description: { zh: "", en: "" },
  images: [],          // 例如 ["./assets/作品名-概念图-01.jpg"]
  video: "",           // 例如 "./assets/作品名.mp4"
  posterImages: [],    // 海报图片路径数组
  playUrl: "",         // 完整游玩地址
}
```

本次所有详情字段保持为空，点击「进入」打开独立详情页，目前保留标题和空白展示区域。填写素材路径后会自动显示相应内容。详情页支持返回对应作品及中英文切换；预览轮盘与淡入尊重系统减少动态效果的设置。

`slots` 只记录文档里的素材需求，不会在页面生成假内容：`conceptImages`、`videos`、`posters` 分别记录概念图、视频和海报数量，`descriptionCharacters` 记录预留简介字数。`null` 表示原文的 n 张、数量待定。

文档影像分区标题写“3个”，实际列出 4 个作品，本次按逐项清单保留 4 个；工具名称 `Thres JS` 和奖项 `S1 S100` 沿用原文，可以直接在内容文件更改。

模式装置由 `portfolio.js` 的 `modeConsole()` 生成 SVG，刻度数量、圆环半径、轨道和星形均可编辑。装置的尺寸、位置、线条透明度、旋转速度及按钮样式在 `portfolio.css` 的 `.mode-console`、`.console-*` 中修改。按钮文案和过渡时长在 `settings.js` 的 `selection` 中；首页、个人介绍、快速浏览和观赏的流程在 `journey.js`。

文案、图片路径、流星速度、间隔、大小范围和轨道高度集中在 `settings.js`。流星同时出现多颗，尺寸、尾迹、亮度及出现间隔随机变化，方向统一沿圆弧从左向右。字体、字号、文字位置和橙色文字在 `style.css`。

首图位于 `assets/hero-orbit.png`。图片尺寸和天体的圆弧在 `app.js` 的 `imageSize`、`horizon` 中设置。如果换用构图不同的图片，需要同步更新图片尺寸和圆弧。

英文字体使用接近参考图衬线风格的 Cormorant Garamond，并压低大标题字形高度。中文使用 Noto Sans SC ExtraLight 字体子集，已覆盖本次文档和界面文案，文件为 `assets/noto-sans-sc-portfolio.ttf`。新增子集之外的文字时会使用系统细体回退，也可以重新生成字形子集。字体均随站点提供，许可见 `assets/Cormorant-OFL.txt` 和 `assets/Noto-OFL.txt`。
